# CR Configuration

## 严重级别定义

| 级别 | 定义 | 必须修复 | CR 阻断 |
|------|------|----------|---------|
| P0-Critical | 线上事故风险 | 是 | 是 |
| P1-High | 功能正确性风险 | 是 | 是 |
| P2-Medium | 部分场景风险 | 建议 | 否 |
| P3-Low | 代码质量 | 可选 | 否 |

## 规模阈值

| 规模 | 文件数 | 行数 | 审查策略 |
|------|--------|------|----------|
| 小 | ≤5 | ≤200 | 快速审查，聚焦风险 |
| 中 | 6-20 | 201-800 | 标准审查 |
| 大 | 21-50 | 801-2000 | 分模块审查 |
| 超大 | >50 | >2000 | 建议拆分变更或缩小范围 |

## 扫描范围控制

### 排除文件后缀

`.png`、`.jpg`、`.jpeg`、`.gif`、`.svg`、`.ico`、`.ttf`、`.otf`、`.woff`、`.woff2`

### 排除目录

| 平台 | 排除目录 |
|------|----------|
| Android | `build/`、`.gradle/`、`.idea/`、`.gradle/` |
| iOS | `Pods/`、`DerivedData/`、`*.xcworkspace/`、`*.build/`、`Carthage/` |
| HarmonyOS | `oh_modules/`、`.preview/`、`build/`、`entry/build/` |
| 通用 | `node_modules/`、`.cache/`、`vendor/`、`.git/` |

### 排除文件模式

`*.lock`、`*.generated.*`、`R.java`、`R.txt`

### 大变更提醒阈值

超过 50 个文件变更时提醒用户缩小范围。

## 跨平台对比规则

- 功能缺失判断阈值：一端实现完整逻辑（>10 行），另一端完全无对应代码
- 行为差异判断标准：归一化描述中的"关键逻辑"不一致
- 平台特有功能标记：因平台限制或策略有意不实现的功能，不作为差异
- 等价实现标记：实现方式不同但业务行为一致，标记为 P3 实现差异
