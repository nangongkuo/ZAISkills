# 单平台 CR 输出模板

报告直接写入 `.md` 文件，方便人工审核和修改。

```md
---
type: cr-report
mode: single
platform: <Android|iOS|HarmonyOS>
repo: <仓库路径>
base: <基准分支/commit>
head: <目标分支/commit>
date: YYYY-MM-DD HH:mm
---

# CR 报告:【项目名】（【平台】）

**变更范围**: `<base>` → `<head>`
**变更规模**: N 个文件，+N/-K 行
**审查时间**: YYYY-MM-DD HH:mm

---

## 变更摘要

- 核心意图: <一句话>
- 影响模块: <模块列表>
- 变更类型: <新增功能 / Bug修复 / 重构 / 配置 / 混合>

---
```
