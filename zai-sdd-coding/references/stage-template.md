# 阶段模板

**说明**：此文件为阶段模板，创建新阶段时复制并修改。

---

## 输入 Schema

| 字段 | 来源 | 类型 | 必填 | 说明 |
|------|------|------|------|------|
| repo_path | state.基本信息.仓库路径 | string | ✅ | 仓库绝对路径 |
| branch_name | state.基本信息.分支名 | string | ✅ | 当前分支名 |
| xxx | state.阶段N.xxx | string | ❌ | 示例字段 |

**来源说明**：
- `state.基本信息.xxx` - 从状态文件基本信息表读取
- `state.阶段N.xxx` - 从阶段N的输出中读取

---

## 输出 Schema

| 字段 | 写入位置 | 类型 | 说明 |
|------|----------|------|------|
| xxx | state.阶段N.xxx | string | 示例输出字段 |

---

## 步骤清单

> 开始执行前实例化，每步完成后标记 ✅，输出 `[NEXT: stage=N+1]` 前逐项确认。

- [ ] Step 1：<步骤名称>
- [ ] Step 2：更新 state.md

---

## 执行步骤

### Step 1：步骤名称

步骤描述...

```bash
# 示例命令
```

---

### Step 2：更新状态文件

**路径**：`<仓库路径>/.acs-sdd-coding/state.md`

追加到状态文件：

```markdown

### 阶段N：<阶段名>
状态：✅ 完成
完成时间：<ISO时间>
执行模式：<从配置读取>
执行耗时：<秒数>秒
<按输出Schema写入字段>

问题记录：[]

## 待执行
下一阶段：<N+1 或 null>
```

更新基本信息：
- 当前阶段：N → N+1
- 更新时间：<ISO时间>

## 完成前验证

> 步骤清单全部 ✅ 后，逐项执行以下验证。全部通过才可输出返回摘要。

| # | 验证项 | 检查方式 | 不通过时修复动作 |
|---|--------|----------|------------------|
| 1 | `state.md` 包含本阶段输出 | `grep "阶段N" state.md` | 立即写入 |
| 2 | <其他产物验证> | <检查方式> | <修复方式> |

---

## 返回摘要

**格式**（不超过200字）：

```
╭────────────────────────────────────────────╮
│              ✅ 阶段 N 完成              │
╰────────────────────────────────────────────╯

<核心结果摘要>

────────────────────────────────────────────
👉 进入【阶段 N+1：<阶段名>】
```
