# 阶段1：输入收集与初始化 - 交互文案

## 阶段入口

```
📋 阶段1：输入收集与初始化

本阶段收集开发所需的全部信息，并完成知识准备。

请输入：
1. 系分文档（语雀URL或直接描述）
2. 设计稿（可选，DMore链接）
3. 分支名称

或输入 skip 跳过某项，? 查看帮助，exit 退出
```

---

## 系分文档

**询问:**
```
步骤 1/3：系分文档

请提供系分文档信息：
• 语雀URL（推荐）：https://yuque.antfin.com/xxx
• 文档标题：搜索相关内容
• 直接描述：简要功能需求

→ 输入（skip跳过）：
```

**成功:**
```
✅ 系分文档已读取：{doc_title}

核心需求：{summary}

确认继续？ [Y/n]
```

**失败:**
```
⚠️ 读取失败：{error}

请检查权限或重新输入 [R/skip/exit]：
```

---

## 设计稿

**询问:**
```
步骤 2/3：设计稿（可选）

是否有设计稿？
• DMore链接：https://dmore.alipay.com/xxx
• 图片路径：/path/to/design.png
• skip：无设计稿

→ 输入：
```

**已收集:**
```
✅ 设计稿已记录：{design_name}

是否还原代码？ [Y/n]：
```

---

## 分支创建

**询问:**
```
步骤 3/3：分支创建

当前分支：{current_branch}
请输入新分支名：
• 直接输入：feature/xxx
• auto：自动生成

→ 分支名：
```

**已存在:**
```
⚠️ 分支 '{branch_name}' 已存在

[1] 切换并继续
[2] 重新输入
```

**成功:**
```
✅ 分支创建成功：{branch_name}
```

---

**执行中:**
```
📦 知识准备中...

✅ CLI 检查：{cli_status}
✅ 远程同步：{sync_status}
✅ 知识索引：{index_status}
✅ Schema 部署：{schema_status}
```

**完成:**
```
━━━━━━━━━━━━━━━━━━━━
📋 输入收集与初始化完成

系分：{doc_status}
设计稿：{design_status}
分支：{branch_name}
知识：{repo_count} 条仓库 + {common_count} 条通用

✅ 阶段1完成

```

---

## 快捷命令

| 命令 | 作用 |
|------|------|
| skip | 跳过当前输入 |
| auto | 自动生成分支名 |
| ? | 查看帮助 |
| Y/n | 是/否 |
| exit | 退出 |
